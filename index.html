Web flasher: pick your board, then install the firmware over USB
⚠ Unofficial fork This is not the original project. This firmware comes from the fork Eifel-Joe/SpoolmanScale. The original is Niko11111/SpoolmanScale. Please report problems with this fork at Eifel-Joe/SpoolmanScale, not at the original.

Your board

Each image is made for one board. On any other board it will not work.

Choose your board to get the Install button.

Before Flashing

  1. Connect a USB data cable to your PC and to the board; if it has both a USB and a UART connector, use USB
  2. Click "Install", select the port and confirm
  3. After flashing: enter your WiFi right in the browser
⚠ Your settings Flashing here erases the scale's settings (WiFi, calibration, backend). The browser asks for your WiFi again afterwards. To keep your settings, update through the scale itself instead (its web interface, Firmware tab). A scale that cannot update itself: save its settings first in its web interface under "Backup and restore", and load them there again after flashing.
This browser does not support Web Serial.
Please use Chrome or Edge. No USB access. Open this page via HTTPS or localhost.

The installer has not loaded. If no Install button appears, reload the page; the installer comes from unpkg.com, which this browser must be able to reach.

Flashing fails with "Failed to initialize"? Close anything else that uses the USB port (a second flasher tab, Arduino IDE) and use a data cable plugged straight into the computer, no hub. Still failing, and if your board has BOOT and RESET buttons: hold BOOT, press and release RESET, release BOOT, then click "Install" again. Press RESET once when flashing is done.
