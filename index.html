SpoolmanScale – Fork
Web flasher for the Waveshare ESP32-S3-Touch-LCD-7B (1024×600)
⚠ Unofficial fork, test build This is not the original project. This firmware comes from the fork Eifel-Joe/SpoolmanScale (branch feat/waveshare-7b) and is an untested first build for the Waveshare 7B board. Do not use it on other boards. The original is Niko11111/SpoolmanScale; please do not report problems with this fork there.

Before Flashing

  1. Connect a USB data cable to the board's "USB" connector (not "UART") and to your PC
  2. Click "Install", select the port and confirm
  3. After flashing: enter your WiFi right in the browser
⚠ Your settings If the flasher asks whether to erase the device: left unticked, your settings survive; ticked, the scale starts empty.
This browser does not support Web Serial.
Please use Chrome or Edge. No USB access. Open this page via HTTPS or localhost.
Flashing fails with "Failed to initialize"? Close anything else that uses the USB port (a second flasher tab, Arduino IDE) and use a data cable plugged straight into the computer, no hub. Still failing: hold BOOT, press and release RESET, release BOOT, then click "Install" again. Press RESET once when flashing is done.
